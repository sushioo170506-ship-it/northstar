## 指标解释与限制

- 20/20 是本地确定性实现的受控样本，满足测试集上的“不低于 95%”，不代表外部模型、网络
  或检索服务在生产环境中的长期 SLA。生产成功率应通过真实负载、故障注入和持续监控统计。
- 必需历史上下文使用产物 ID 精确加载、完整分片重组和 SHA-256 校验，因此测试路径可验证
  100% 无损读取。向量语义查询是辅助召回，不能对任意未知查询宣称 100% 召回率。
- 十万字测试验证九个 Skill 的内置实现没有截断和内存溢出；外部 LLM 适配器仍需按章节调用，不能把完整
  文本一次性塞入模型上下文。
- 当前测试未覆盖多主机并发，因为内置后端是明确的单机 SQLite；多实例部署需要 PostgreSQL
  与生产向量库适配器及租约测试。
