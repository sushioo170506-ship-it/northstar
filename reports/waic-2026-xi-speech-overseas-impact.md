# 习近平主席 WAIC 2026 主旨讲话海外传播与影响力监测报告

**监测窗口：** 2026-07-10 — 2026-07-30（讲话日：2026-07-17）  
**讲话题目：** *Joining Hands to Build a Just and Equitable System For Global AI Governance*  
**数据采集时间：** 2026-07-30  
**数据来源：** social-superpowers MCP（Reddit / X）、yt-dlp（YouTube）、xpoz MCP（Instagram / TikTok 试探）、公开外媒检索（Reuters、SCMP、CNA、DW、Quartz 等）

---

## 一、执行摘要

2026年7月17日，习近平主席首次亲临世界人工智能大会（WAIC）开幕式并发表主旨讲话，提出开放开源、安全可控、包容共享、公正治理四点主张，并宣布世界人工智能合作组织（WAICO）落地上海、面向发展中国家的能力建设举措。监测显示：

1. **国际主流媒体形成跨地区报道网络**，路透社、南华早报、CNA、DW、彭博、Quartz 等十余家英文媒体及新华社/CGTN 英文渠道同步发声，路透社通稿被多家媒体转载。
2. **海外社媒出现可观测讨论峰值**，尤其在 Reddit 开源 AI 社区（r/LocalLLaMA、r/singularity 等）与 X 平台，用户对「开源开放」「南方国家能力建设」「AI 不应由一国独奏」等表述回应积极。
3. **情感结构以「中性报道 + 建设性正面评价」为主**，地缘博弈解读并存；开源开发者与部分全球南方相关讨论中，对中国人工智能开放路径的认可度明显高于纯政治对抗叙事。
4. TikTok、Facebook、Quora 等平台公开可检索的高质量相关样本偏少或噪声极大，**不宜夸大其「全民热议」程度**；海外关注的主通道目前是**国际新闻 + YouTube + Reddit/X + 专业社群**。

总体判断：讲话在海外引发了**超出一般行业峰会的政策级关注**，并在「开源公共品」「全球南方包容」「多边治理」议题上获得了**可核验的正面回应**，有助于塑造中国作为负责任人工智能公共产品提供者的国际形象。

## 三、数据采集方法

### 3.1 检索策略

- **关键词组合：** `Xi Jinping WAIC` / `World AI Conference` / `WAICO` / `open source` / `historical injustice` / `symphony of international cooperation`
- **严格相关过滤：** 标题或正文需命中 WAIC / WAICO / World AI Conference，或同时出现 Xi + AI +（open source / governance / Shanghai）
- **去重：** 按帖文/推文/视频 ID 去重

### 3.2 情感标注方法

采用**双层标注**，避免把新闻转述中的「open source / cooperation」误算为「用户点赞」：

1. **内容层（标题/推文文本）**：关键词启发式标注（正面 / 中性 / 负面 / 混合）
2. **评论层（Reddit 重点帖）**：对 7 个高相关帖的人工可读评论样本做建设性/批评性分类

> 说明：启发式情感会受议题词影响而偏正面；**评论层结果更能反映真实用户态度**。

### 3.3 平台覆盖与限制

| 平台 | 状态 | 说明 |
|---|---|---|
| Reddit | ✅ 已采 | social-superpowers |
| X (Twitter) | ✅ 已采 | social-superpowers |
| YouTube | ✅ 已采 | yt-dlp 搜索 |
| Instagram | ⚠️ 有限 | xpoz 关键词检索，相关样本少 |
| TikTok | ⚠️ 噪声高 | 关键词易被无关内容淹没，有效样本不足 |
| Facebook / Quora | ❌ 未形成有效样本 | 公开检索未见稳定讨论串 |
| 外媒 | ✅ 已采 | 网页检索 + 全文核验 |

### 4.5 Instagram / TikTok / Facebook / Quora

- **Instagram：** 可见到中国外交官账号（如 @maoning_mfa）转述 WAICO「里程碑」表述（约 143 赞）；印尼政要相关帖互动更高；另有 WAIC 机器人/产品展示帖。整体**政策讨论密度低于 Reddit/X**。
- **TikTok：** 关键词检索被体育「XI」、校园标签、无关 AI 热门视频严重污染，**本次未能建立可靠的政策话题样本**，故不给出虚高互动统计。
- **Facebook / Quora：** 公开检索未发现可规模化统计的独立讨论串；可见使领馆/地方媒体转发类内容（如利比里亚相关转载），属外交传播延伸而非大众热议。

## 六、情感结构与海外认知画像

### 6.1 综合情感（加权理解，非简单加总）

| 层级 | 正面 | 中性 | 负面 | 说明 |
|---|---:|---:|---:|---|
| Reddit 评论层（最可靠） | 26% | 68% | 6% | 建设性讨论为主 |
| X 文本层（偏议题词） | 64% | 21% | 8% | 含官方传播与金句转发 |
| YouTube 标题层 | 13% | 74% | 13% | 新闻标题偏中性 |

### 6.2 正面回应集中在哪里？

1. **开源开发者社群：** 将讲话视为对中国开源路线的最高层确认，增强「中国开源模型可持续可用」预期。  
2. **中小国家/全球南方视角用户：** 认同「不被两大国关在门外」的可及性叙事。  
3. **多语种公共外交圈：** 金句与 WAICO 叙事被使领馆与地区意见领袖转发。

### 6.3 负面/质疑集中在哪里？

1. 将 WAICO 解读为与美西方治理框架对峙的地缘工具。  
2. 质疑创始成员构成与「World」命名的代表性。  
3. 少数频道以「西方缺席」等进行嘲讽性二次传播。

这些声音存在，但**未压过开源社区与国际媒体对「开放、共享、能力建设」主信息的扩散**。

## 七、对「广泛关注 + 正面回应 + 信心提升」的证据评估

| 主张 | 证据强度 | 依据 |
|---|---|---|
| 引发国外广泛关注 | **强** | Reuters 等通稿级覆盖 + YouTube 约 44 万播放 + Reddit/X 持续讨论 + 政策智库跟进 |
| 获得正面/建设性回应 | **中强** | Reddit 评论层正面显著高于负面；开源社区高认同；多国参与 WAICO |
| 外国人更看好中国 AI 发展 | **中（分群成立）** | 在开源/本地部署用户中证据充分；不能外推为全体西方公众舆论转向 |

可稳健对外表述的版本：

> 习近平主席在 WAIC 2026 的主旨讲话，通过国际主流媒体与海外社媒形成跨平台传播，在开源共享、全球南方能力建设与多边治理等议题上获得了海外技术社群与发展中国家相关舆论的积极回应，显示出国际社会对中国推动人工智能开放合作与公共产品供给的高度关注。

## 八、传播亮点（可用于对外叙事，且有数据支撑）

1. **最高规格：** 首次亲临 WAIC 主旨演讲，被多家外媒视为中国把 AI 治理提升到国家战略外宣层级的信号。  
2. **可引用金句全球流转：** “symphony of international cooperation” 成为跨平台传播记忆点。  
3. **制度输出可见：** WAICO 29 国 + 联合国秘书长在场，构成「倡议—机制—多边背书」闭环。  
4. **与产业事实互证：** 同期中国开源模型进展被海外开发者社区用来印证「开放不是口号」。  
5. **务实承诺可核查：** 5,000 培训名额、区域合作中心、MAZU 30 国，便于后续跟踪报道。

## 九、局限与后续建议

1. 本次为**公开接口抽样**，不是全网普查；X/Reddit/YouTube 数字应标注为「样本内累计」。  
2. TikTok / Facebook / Quora 需账号级或商业社听工具才能做稳健定量。  
3. 建议后续 30/90 天跟踪：WAICO 成员国表态、培训项目落地、开源模型海外下载/部署指标，以把「关注」沉淀为「信心」的长期证据。
