# 习近平主席 WAIC 2026 主旨讲话海外传播监测报告（修订版）

**监测窗口：** 2026-07-13 — 2026-07-23（含首尾）  
**讲话日期：** 2026-07-17  
**数据采集：** 2026-07-30  
**修订说明：** 按委托方规则重算——放宽提及口径、互动=赞+评+转、情感含点赞归属与评论语义。

---

## 一、统计规则（本次口径）

### 1.1 提及量
凡正文/标题命中讲话关键词或要点即计 1 次提及（去重后按帖/视频计）：

- 人物/场合：`Xi Jinping` / `习近平` / `WAIC` / `World AI Conference` / `WAICO`
- 要点表述：`symphony of international cooperation`、`solo performance`、`historical injustice`、`open source` / `open-source`、`Global South`、`people-centered`、`under human control`、`overstretching the national security`、`5,000` 培训、`MAZU`、`just and equitable` 等

### 1.2 浏览量
以平台可返回的浏览/播放字段为准（本次主要为 YouTube `view_count`）。

### 1.3 互动量
**点赞 + 评论/回复 + 转发/分享** 合计。

### 1.4 情感分析（加权单元）

| 信号 | 规则 |
|---|---|
| 帖文本身 | 正面（亲中/支持开放合作等）/ 中性（纯报道）/ 负面（辱华、嘲讽、明确反华框架） |
| 点赞 | 帖文正面 → 正面；帖文负面 → 负面；**帖文中性 → 计为正面**（因讲话内容本身正面积极） |
| 转发 | 与点赞同规则（放大传播视为同向态度） |
| 评论 | 支持帖文/支持中国/支持合作、批评美西方遏制等 → **正面**；辱华、反华攻击等 → **负面**；其余 → 中性 |

**情感占比** = 各极性「情感单元」之和 / 总单元。  
情感单元 = 帖文条数贡献 + 归属后的点赞数 + 归属后的转发数 + 已标注的评论文本条数。

> 说明：Reddit 点赞分、YouTube 点赞/评论因接口限制未能取得，故这两端互动/情感不完整；Instagram 互动高度集中于少数政要帖，解读时需分平台看。

## 三、分平台结果

### 3.1 Reddit（提及 61）

- **互动：** 669（全部为评论数；点赞接口不可用）
- **帖文：** 正面 17 / 中性 44 / 负面 0（标题层；多数为新闻转载式中性标题）
- **评论语义（已抽样标注）：** 正 143 / 中 483 / 负 24  
  - 正面评论典型方向：认同开源与全球南方可及性、认为讲话比西方 AI 巨头「更sensible」、批评美西方封闭/遏制  
  - 负面评论：指控宣传、质疑动机等，占比较低
- **情感单元：** 正 22.5% / 中 74.1% / 负 3.4%  
  （中性偏高，因大量技术讨论评论未明确站队，且缺点数赞拉升正面权重）

**解读：** 开源社区（如 r/LocalLLaMA、r/singularity、r/Futurology）对「开源开放、防止历史不公正」回应建设性偏正；纯辱华声音很少。

### 3.2 X / Twitter（提及 59）

- **互动：** 3,636 = 赞 2,822 + 回复 172 + 转发 642
- **帖文：** 正面 46 / 中性 9 / 负面 4
- **点赞+转发归属：** 正面向 3,121；负面向 343
- **情感单元：** **正 89.9% / 中 0.3% / 负 9.8%**

高互动正向样例：

- 讲话全文转述（@juddrosenblatt 等）互动 1,000+  
- WAICO / 全球南方培训要点图文解读  
- 「symphony of international cooperation」金句传播  

负面样例多为对华战略动机的长文批评；按规则其点赞计入负面。

### 3.3 YouTube（提及 71）

- **浏览量：** **414,826**
- **互动：** 赞/评因 bot 墙未能拉取（计 0）
- **标题情感：** 正 8 / 中 60 / 负 3（路透、SCMP、CNA、Bloomberg、CNBC-TV18 等偏中性快讯）
- **情感单元（仅标题）：** 正 11.3% / 中 84.5% / 负 4.2%

若日后补齐点赞：按规则，中性新闻标题下的点赞应计入**正面**，预计正面占比会明显上升。

### 3.4 Instagram（提及 7）

- **互动：** 12,421（赞 12,356 + 评 65）
- 含印尼政要相关 WAIC 场合帖（高赞）、外交官 WAICO 表述帖、巴基斯坦媒体 WAICO 创始成员帖、会展科技展示帖等
- 中性帖点赞按规则计入正面 → 情感单元正面接近 100%
- **注意：** 单帖权重高，不宜单独外推「Instagram 全民热议」

### 3.5 TikTok / Facebook / Quora

窗口内公开检索**未形成可规模化、低噪声的政策讨论样本**（噪声标签、体育 “XI”、校园标签等干扰大），本次不虚报提及/互动。

## 四、情感结构说明（为何综合正面达 94.2%）

综合正面占比高，主要来自：

1. **X 平台**大量金句/要点转发 + 点赞/转发按「中性亦算正面」归属；  
2. **Instagram** 高赞政要/外交相关帖的点赞归属；  
3. Reddit 虽评论中性多，但负面评论仅约 3–4% 量级。

若去掉 Instagram 后重新估算（仅 Reddit+X+YouTube 标题）：

| 指标 | 数值 |
|---|---:|
| 提及 | 191 |
| 互动 | 4,305 |
| 浏览 | 414,826 |
| 情感单元 正/中/负 | 3,335 / 596 / 374 |
| 正面占比 | **约 77.4%** |

即便剔除 IG 高赞帖，正面仍显著高于负面，结论方向不变。

## 五、外媒与机制背景（窗口内）

窗口内国际报道仍构成「广泛关注」的重要底座：

- **Reuters** 通稿级报道并被多家转载  
- **SCMP、CNA、DW、Bloomberg、Quartz** 等跟进开源、全球南方、人类监督等要点  
- **WAICO** 29 国创始机制 + 联合国秘书长相关出席，强化多边可见度  

外媒标题多为中性议程设置；与社媒「开源社区建设性认同」形成互补。

## 六、结论（按新口径）

在 **2026年7月13日至23日** 监测窗口内：

1. **提及量 198**：海外社媒与视频平台对讲话关键词/要点形成可观测扩散。  
2. **浏览量约 41.5 万**（YouTube 可测部分），说明影像与新闻二次传播触达可观。  
3. **互动量约 1.67 万**（可测赞评转），主要来自 X 与 Instagram，Reddit 以评论讨论为主。  
4. **情感分布以正面为主**：按委托规则计入点赞归属后，综合正面情感单元约 **94%**（剔 IG 后约 **77%**），负面约 **2–10%** 量级；开源合作、全球南方能力建设、反对技术垄断等叙事获得海外建设性回应。

可对外表述：

> 监测显示，习近平主席 WAIC 主旨讲话在 7 月 13–23 日窗口内于海外社媒与视频平台形成明确提及与传播；在可统计互动中，按内容与点赞/评论综合规则测算，正面响应占主导，反映出国际舆论对中国推动人工智能开放合作、支持全球南方与多边治理主张的积极关注。
