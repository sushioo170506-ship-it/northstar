## 核心结论（定刺）

- **结论**: Mythos 5 不是「更强的模型」，而是「同一底座的受限准入版」——多数团队该评的是 Fable 5，追 Mythos 准入是采购死胡同。
- **反对者会说**: Anthropic 自称 Mythos 5 拥有「全球最强网络安全能力」；去掉护栏后在 cyber/bio 上实质更强，不能说「一样」。
- **证伪条件**:
  1. 独立第三方在**非受限通用任务**上证明 Mythos 5 系统性显著优于 Fable 5；或
  2. Fable 5 安全分类器误伤率高到使通用研发任务实质降级到 Opus 4.8，导致「同底座」名存实亡；或
  3. Trusted Access 在短窗口内对普通企业全面放开，使「准入产品」判断失效。

## 章节骨架（拆骨）

### §1 全景判断 — 结构分化检验

- **章节结论**: 「最强 Mythos」叙事把两个产品揉成一个——公开可买的是 Fable 5；Mythos 5 是护栏差异产品，不是能力代际。
- **读者质疑**: 你凭什么说不是更强模型？官方跑分和媒体标题不都在吹 Mythos 吗？
- **回应方式**: 结构分化——按「底座能力 / 护栏策略 / 准入范围 / 定价」四维拆开；对照官方原文「same underlying model」。
- **锚点**: **对比锚** — Anthropic 官方表述：Fable 5 与 Mythos 5 共享同一底层模型，差异在部分领域安全分类器是否抬起；API 定价同为 **$10 / $50 per MTok**（相对 Mythos Preview 的 $25/$125 降约 60%，待 Step 2 核对官方 changelog）。

### §2 深度评比 — 多维评分 + 实景

- **章节结论**: 在可公开验证的赛道上，决策对象应是 Fable 5 vs Opus 4.8 / GPT-5.5 / Gemini 3.1 Pro；Mythos 5 只在「护栏抬起的 cyber/bio 任务」上构成不可替代差分。
- **读者质疑**: 你的评分标准是什么？有什么资格把 Mythos 从「旗舰对比表」里拿出去？
- **回应方式**: 公开 5–6 维评分（硬基准 + Token 效率 + 长程 Agent + 生态/工具链成熟度 + 真实场景可用性 + 合规/准入摩擦），选手覆盖标杆+中坚；Mythos 单列「差分能力」行而非总分掺水。
- **锚点**: **数据锚** — 待采：SWE-bench 类 / 视觉文档推理（如 GDPval-style）/ FrontierCode 等公开数字；**案例锚** — 待采：Fable 分类器触发后降级 Opus 4.8 的官方说明与「>95% 会话不触发」类表述的独立核验；社区实景（延迟、限流、误拒）。

### §3 格局推演 — 情景 + 时间窗口

- **章节结论**: 2026 H2 的主战场是「Mythos 级能力大众化（Fable）」与「双用途能力受控释放（Mythos/Glasswing）」并行；普通企业赢面在 Fable 落地效率，不在排队等 Mythos。
- **读者质疑**: 你怎么知道 Trusted Access 不会很快放开、让 Mythos 变成标配？
- **回应方式**: 三情景（高/中/低确定性）+ 触发条件（监管、Glasswing 扩容、生物方向开放、竞品对等双轨）。
- **锚点**: **数据锚** — 待采：Glasswing 伙伴范围、Mythos Preview→Mythos 5 迁移政策、30 天流量强制留存政策对采购的影响；时间线：2026-04 Preview → 2026-06-09 Fable/Mythos 5。

### §4 决策工具 — Checklist

- **章节结论**: 若你不是受审的网络防御/关键基础设施（及后续生物研究）伙伴，默认选型 Fable 5；只有「必须在分类器会降级的攻击面/生物工作流上跑满血」才申请 Mythos。
- **读者质疑**: 具体怎么做？预算和风险怎么权衡？
- **回应方式**: 场景→推荐模型→理由→否决条件 决策表；附 TCO 粗算（相对 Opus 4.8 约 2× 标价 vs Token 效率是否打平）。
- **锚点**: **对比锚** — 定价锚：$10/$50（Fable=Mythos）vs Opus 4.8 $5/$25 vs 竞品旗舰；**案例锚** — 待采：何种请求被路由到 Opus 4.8（官方 fallback 文档）。

## 传播节奏（设门+埋钩）

- **头门（3 秒入口）**: 「你要评的不是 Mythos 5——公开最强 Claude 叫 Fable 5。」
- **中间门**:
  - §1 入口段: 官方写明同底座；媒体标题把「Mythos」当成代际名。拆开看：能力共享，差异在护栏与准入。定价同为 $10/$50，Preview 降价约六成是价格事件，不是「Mythos 更强」证据。
  - §2 入口段: 把 Mythos 从总分赛里拿出去，改成「差分能力」行。公开赛道评 Fable；cyber/bio 满血才是 Mythos 的存在理由——用评分表证明，不靠口号。
  - §3 入口段: 双轨会成为超强模型标配：大众化一条、受控双用途一条。企业策略应押 Fable 落地，把 Mythos 当期权而非主路径。
  - §4 入口段: 一张表决定：你是不是 Glasswing 类用户？不是 → Fable；是且任务会被分类器降级 → 申请 Mythos。其余争论都是噪音。
- **尾门（闭环末尾）**: 「先买 Fable 跑通工作流；没降级痛点，就别为 Mythos 排队。」
- **节奏分配**: 前 30% 捅刀子（同底座拆穿）/ 中 40% 深钻（评分+实景+假说检验）/ 后 30% 工具+闭环

**字数预算（供 Step 4）**: 头门 100–150 · 核心判断 300–400 · 深度评比 1200–1800 · 格局 400–600 · 决策 400–600 · 尾门 150–200｜合计约 3000–4000 字

## 刺点清单

| # | 行业共识（易被默认） | 刺点判断 | 检验方式 |
|---|---------------------|----------|----------|
| 1 | 「Mythos 5 = 目前最强、该优先追的旗舰」 | 对公众与多数企业，决策对象是 **Fable 5**；Mythos 是准入差分产品 | 核对官方是否写明同底座；对比公开 API 可得性 |
