## 核心结论（定刺）

- **结论**: 对中国团队，Mythos 5 不是"能买的更强 API"——它是一个 18 天就被政府一键关停、且疑似对华用户做了隐写追踪的地缘样本；真该对标的是 Fable 5 的公开能力与"双轨发布"制度。
- **反对者会说**:
  1. Mythos 5 SWE-Bench Pro 80.3%、ExploitBench 78%，是全球最强，谈"进不去"是酸；
  2. 出口管制已于 6/30 解除、Fable 5 已全球恢复，"关停风险"是旧闻；
  3. 国内模型跑分离 80% 还差 20 分，谈"对标制度"是回避真实能力差距。
- **证伪条件**:
  1. Anthropic 对中国区提供稳定、无准入门槛、无追踪争议的 Mythos 5 通用 API；或
  2. 独立第三方证明国内旗舰在公开 Agent/编码基准上已系统追平 Fable 5（≤3 分内）；或
  3. 出口管制机制被证明为一次性事件、不再重演，可用性风险归零。

## 章节骨架（拆骨）

### §1 研究背景与模型介绍（定位 · 能力 · 安全评估）

- **章节结论**: Mythos 5 与 Fable 5 同底座、同价、同能力，差异只在"护栏是否抬起 + 谁能用"——它是能力分级发布的制度产物，不是新一代更大模型。
- **读者质疑**: 媒体都在说"最强 Mythos"，为什么一上来就拆成两个名字？安全评估是不是公关？
- **回应方式**: 背景压成一条时间线（2026-04 Preview → 06-09 双轨发布 → 06-12 被管制关停 → 06-30 解禁）；定位/能力/安全评估三块用官方+第三方基准落实。
- **锚点**: **对比锚** — 官方 "same underlying model, name reflects safeguard difference"；同价 $10/$50；`claude-fable-5` vs `claude-mythos-5`。**数据锚** — SWE-Bench Pro 80.3%、ExploitBench 78.0%、上下文 1M。

### §2 横向对比：与国内模型——能力角度

- **章节结论**: 公开可核验的能力账要拿 Fable 5（可全球调用）对国内旗舰；纸面差距真实存在（SWE-Bench Pro 80.3% vs 国内最高 ~58.6%），但价格差 30–70 倍是另一半事实。
- **读者质疑**: 国内选谁比？维度凭什么？会不会偏袒海外？
- **回应方式**: 固定选手池 + 公开维度评分（Step 3），Mythos/Fable 合并为一个"海外锚"行，避免满血泡沫。
- **锚点**: **数据锚** — SWE-Bench Pro：Fable/Mythos 80.3% vs Kimi K2.6 58.6% / GLM-5.1 58.4% / DeepSeek V4 ~52%。**对比锚** — 单价：Fable $10/$50 vs DeepSeek V4 Flash $0.14/$0.28（约 70–180 倍）。

### §3 横向对比：与国内模型——场景角度 + 局限与风险

- **章节结论**: 场景上国内赢在"可自托管 + 合规可控 + 价格"，海外赢在"长程自主与最高难度工程"；但对中国团队，最大的不是能力风险，是**可用性与主权风险**——18 天关停 + 疑似隐写追踪。
- **读者质疑**: 场景对比会不会变印象流？"追踪"是不是阴谋论？
- **回应方式**: 场景矩阵（编码 Agent / 科研 / 安全 / 中文业务 / 私有化）逐格判"更适合谁"；局限与风险独立成块，追踪一事标注来源等级与"存疑"。
- **锚点**: **案例锚** — 6/12–6/30 出口管制关停 18 天；Amazon 研究者越狱报告触发管制；观察者网报道疑似 Claude Code 隐写回传中国用户标记（媒体来源，标注存疑）。**数据锚** — 国内 1M 上下文默认、MIT/Apache 开源、$0.14 起价。

### §4 战略启示（决策工具）

- **章节结论**: 学双轨、对标 Fable、业务用国内、把海外旗舰当"能力标尺 + 应急备份"而非主依赖；受管制/追踪风险决定了国内团队不能把主链路架在 Mythos/Fable 上。
- **读者质疑**: 具体谁该怎么做？会不会太正确而无用？
- **回应方式**: 分角色 Checklist（模型厂商 / 应用企业 / 安全合规 / 投资研究），每格 场景→推荐→理由→否决条件；附 TCO 与"断供演练"建议。
- **锚点**: **对比锚** — 一页决策表 + 价格/可用性/合规三轴权衡。

## 传播节奏（设门+埋钩）

- **头门（3 秒入口）**: "全球最强模型上线 3 天被政府关停，18 天后才回来——中国团队用不上它。"
- **中间门**:
  - §1: 先分清 Fable 与 Mythos——同底座、同价、差在护栏与准入；背景用一条时间线讲完。
  - §2: 能力对比把国内旗舰拉齐到 Fable 口径；80.3% vs 58.6% 的差距真实，但价格差 30–70 倍也真实。
  - §3: 场景矩阵显示"中文可控 vs 长程工程"错位；真正的坑是关停与追踪，不是跑分。
  - §4: 三张决策表——厂商补长程 Agent、企业押国内主链、合规做断供演练。
- **尾门（闭环末尾）**: "把 Fable 当标尺，别当地基——它的开关不在你手里。"
- **节奏分配**: 前 30% 定位与刺点 / 中 40% 能力+场景对比与风险 / 后 30% 战略清单与闭环

**字数预算**: 总 3000–4000；§2+§3 合计 ≥ 全文 50%。
