## Recommended Workflow

`scope -> outline -> collect -> process -> write -> review -> output`

回路规则：
- `step4 -> step3`（素材缺失）
- `step6 -> step3`（事实性问题）
- `step6 -> step4`（完整性问题）
- `step6 -> step5`（风格/逻辑/可读性问题）

质量底线（长篇）：
- 来源 >= 12
- benchmark 指标 >= 8
- 竞品 >= 3
- 表格 >= 6
- 图表规格 >= 3
- 复核总分 >= 85
