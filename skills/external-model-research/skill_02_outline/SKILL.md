# mr-step2-outline

name: mr-step2-outline  
description: Step 2 — 构建报告骨架，确定章节结构，并标注每个章节需要的素材类型。

## 作用
大纲不是最终目录，而是“为回答 Step 1 的核心问题，我需要收集什么信息、按什么顺序呈现”的结构化方案。

## 输入
- `archive/scope.md`（Step 1 产出）
- 模型名称

## 输出
写入 `archive/outline.md`（章节大纲，含素材需求与图表需求标注）。

## 预设骨架（按报告类型选择）
- 骨架 A：技术选型型（§1 模型全景 ... §7 结论与建议）
- 骨架 B：安全审查型（来源、版权、安全、偏见、合规、处置）
- 骨架 C：投资研判型（定位、护城河、团队、商业化、竞品、风险、判断）
- 骨架 D：竞品追踪型（版本增量、升级点、评测对比、影响、跟踪项）

## 裁剪规则
- 简报型：可合并 `§1+§2`、`§3+§4`，保留 §7。
- 管理层读者：弱化技术细节，强化对标和结论。
- 技术读者：强化技术拆解和评测细节。
- 安全审查类：使用骨架 B，忽略非必要选型维度。

## 章节标注模板
```md
## §3 能力评测
核心问题: 这一章要解决什么问题？
篇幅权重: xx%
素材需求:
  - ...
需要生成的图表:
  - ...
```

## 质量卡口
- 已根据报告类型选择预设骨架。
- 已按读者画像与篇幅约束裁剪。
- 每章均标注核心问题。
- 每章均标注素材需求。
- 需要图表的章节均提前标注。

## 交接
将 `archive/outline.md` 交给 `mr-step3-collect`。
