# mr-step5-write

name: mr-step5-write
description: Step 5 — 用结构化证据完成正文写作，输出可被多角色直接使用的模型画像报告。

## 定位与作用
本步骤是“表达成稿层”。  
核心目标不是堆信息，而是把证据组织成清晰、可追溯、可执行的结论链。

## 输入
- `archive/processed_data/`
- `archive/outline.md`
- `archive/scope.md`

## 输出
- `archive/report.md`

## 长篇写作门槛
- 篇幅目标：8000-15000 字（如 scope 指定更高，按 scope 执行）；
- 全文引用表格 >= 12，图表规格 >= 4；
- 核心章节（§2-§6）每章至少包含：判断句 + 证据 + 解读 + 局限。

## 写作方法
1. 按“能力证据优先”的章节顺序写作；
2. 每段首句声明段落职能（判断/对比/解读/行动）；
3. 关键数字必须配解释，不做“裸数据”陈列；
4. 技术部分采用三段式（现象/溯源/本质）；
5. 关键章节体现双轨分析（能力轨/治理轨）。

## 结论章节（§7）必备结构
- 模型定位
- 能力判断
- 场景结论（适用/不适用/前提）
- 效果与边界
- 启示与动作
- 90 天路线图
- 加权评分卡（可选附评级）

## 质量卡口
- 结论五要素齐全；
- 所有核心结论可回链证据；
- 文风与目标读者匹配；
- 若证据密度不足，回退 Step4 补证据块后重写。

## 交接
将 `archive/report.md` 交给 `mr-step6-review`。
