# 质量卡口

## 一票否决

出现任一项时不得交付：

- 关键来源无法访问、来源身份不明或疑似编造；
- 数字、日期、专名、引语与原文不一致；
- 引用存在但实际内容不支持对应主张；
- 推断或预测被写成已证实事实；
- 将相关性写成因果关系，但没有相应研究设计；
- 图表数字与正文或证据台账不一致；
- 机密资料被发送给未获授权的远程服务；
- 高风险主题隐瞒会改变决策的重要限制。

## 阶段卡口

### 任务与大纲

- [ ] 主题、目的、读者和篇幅明确
- [ ] 核心问题可证伪
- [ ] 每个问题至少有一个竞争性假说或替代解释
- [ ] 章节共同形成逻辑链，而不是资料分类目录
- [ ] 每节有明确的证据需求和停止条件

### 证据

- [ ] 搜索摘要未被当作最终证据
- [ ] 关键事实有紧邻引用
- [ ] 来源独立性已检查
- [ ] 资料冲突和口径差异已记录
- [ ] D 级来源未支撑关键结论
- [ ] 预测包含时间、方法、情景和触发条件

### 数据与评分

- [ ] 数据清洗、转换和公式可复算
- [ ] 缺失值和异常值处理已说明
- [ ] 统计方法与数据类型匹配
- [ ] 评分指标方向和权重明确
- [ ] 定性判断未被包装成虚假精确分数
- [ ] 权重变化的敏感性已检查

### 正文

- [ ] 执行摘要可以独立阅读
- [ ] 事实、分析和建议明确区分
- [ ] 每段主要推进一个判断
- [ ] 每个数字包含时间、单位、地区、口径和来源
- [ ] 结论明确说明置信度和适用边界
- [ ] 建议对应目标读者能够采取的行动
- [ ] 字数在目标的 ±10% 内，或解释偏差原因

### 引用

- [ ] 正文引用与参考资料一一对应
- [ ] DOI、作者、标题、日期与原始页面一致
- [ ] 引用格式统一
- [ ] 没有未被正文使用的参考条目
- [ ] 付费墙或仅摘要来源已标记

### 图表与构建

- [ ] 每张图都有单位、来源、时间范围和样本说明
- [ ] 图表类型适合数据关系
- [ ] 坐标范围没有误导
- [ ] 色盲友好且黑白打印可辨
- [ ] HTML 自包含或明确列出外部依赖
- [ ] 打印和移动端布局可用

## 评分

每项 0–2 分：

| 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 回答研究问题 | 偏题 | 部分回答 | 直接完整 |
| 证据质量 | 低质量/单一 | 基本可靠 | 一手优先且交叉验证 |
| 分析深度 | 罗列资料 | 有解释 | 有机制、反证和边界 |
| 事实与观点 | 混淆 | 偶有模糊 | 全文清晰 |
| 不确定性 | 隐瞒 | 简单提及 | 说明来源和影响 |
| 读者适配 | 不匹配 | 只调整语气 | 结构、术语和建议均适配 |
| 篇幅控制 | 偏差 >20% | 偏差 10%–20% | 偏差 ≤10% |
| 可行动性 | 无 | 泛泛建议 | 有条件、优先级和风险 |
| 引用完整性 | 多处缺失 | 次要缺失 | 关键事实均可追溯 |
| 可读性 | 结构混乱 | 基本清晰 | 层次清楚且无重复 |

交付门槛：没有一票否决项，且至少 16/20。

分数不能抵消一票否决问题。
