# 可配置研究报告工作流

这套工作流把“研究什么、写多长、写给谁看”拆成独立参数，再通过固定的研究与审校步骤生成可追溯的报告。它适合在 Cursor、Claude、ChatGPT 或其他支持联网检索与多步骤执行的 Agent 中使用。

## 快速开始

1. 复制 [`request-template.md`](request-template.md)，填写研究任务。
2. 将填写后的任务和 [`WORKFLOW.md`](WORKFLOW.md) 一起交给 Agent。
3. Agent 应先返回“任务确认卡”和研究计划；确认无误后再执行检索和写作。
4. 交付前用 [`quality-checklist.md`](quality-checklist.md) 做最后检查。

如果不想逐项填写，只需提供三项：

```text
主题：生成式 AI 对独立软件开发者的影响
篇幅：标准（约 3000 字）
读者：懂产品但不熟悉 AI 技术的创业者
```

其余参数由 Agent 使用默认值补齐，并在“任务确认卡”中明确列出。

## 三个核心变量

| 变量 | 作用 | 示例 |
| --- | --- | --- |
| `topic` | 决定研究边界和核心问题 | 中国新能源汽车出海 |
| `length` | 决定问题数量、证据密度和章节深度 | 速览 / 标准 / 深度 / 自定义字数 |
| `audience` | 决定术语、背景解释、结论形式和语气 | 高管 / 投资人 / 专家 / 大众 / 学生 |

篇幅不是简单扩写或删减。不同档位应改变研究深度：

| 档位 | 建议字数 | 核心问题 | 每项关键结论的证据 | 适用场景 |
| --- | ---: | ---: | ---: | --- |
| 速览 | 800–1500 | 1–2 个 | 至少 1 个可靠来源 | 决策摘要、快速了解 |
| 标准 | 2500–5000 | 3–5 个 | 尽量 2 个独立来源 | 内部研究、方案讨论 |
| 深度 | 8000–15000 | 5–8 个 | 至少 2 个，争议点需呈现多方证据 | 战略、投资、专题研究 |

## 默认交付物

- 标题与执行摘要
- 研究范围、口径与方法
- 关键发现及逐条引用
- 分析与不确定性
- 对目标读者有用的启示或建议
- 参考资料清单
- 附录：关键数据、术语或证据表（仅标准/深度档）

## 设计原则

- **结论可追溯**：事实、数字和有争议的判断必须能回到来源。
- **事实与观点分离**：明确区分来源事实、作者推断和建议。
- **先研究后写作**：禁止先生成结论，再寻找支持材料。
- **读者适配不是换语气**：应同时调整解释深度、术语、结构和行动建议。
- **透明表达不确定性**：资料不足、来源冲突或时效限制必须显式说明。
